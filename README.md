# 郭年真個人學術網站

郭年真的個人專業網站，包含個人簡介、學經歷與研究領域。

## 網站內容

- `index.html`：個人簡介、肖像、學術背景與簡歷下載。
- `experience.html`：學歷、學術經歷與專業服務。
- `research.html`：健保與醫療政策、醫療品質與效率、風險校正與智慧醫療。

以原生 HTML、CSS、JavaScript 製作，支援手機瀏覽及鍵盤導覽。內容依據提供的個人簡歷整理。

## 更新與發布

修改 HTML 可更新網站文字，修改 `styles.css` 可調整共用版面。肖像與下載用簡歷位於 `assets/`。

GitHub Pages 使用 `main` 分支的根目錄發布。更新此分支後，GitHub Pages 會重新發布網站。
